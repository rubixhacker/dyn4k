# Writing for readers

Use ISO 24495-1:2023 for human-readable text. Apply ISO 24495-3:2026 to explanations of physics and scientific evidence. Start with the reader's need. Put the action or result first. Use consistent terms, explicit units, and short sentences. Separate observations, inferences, choices, and untested claims. Make requirements and limits easy to find.

Use ASD-STE100 Issue 9 for new code comments. Use approved words and technical terms with one meaning. Use active voice. Keep each sentence on one topic. Limit instructions to 20 words per sentence and descriptive text to 25. Define project terms when needed. Keep comments only where they explain a constraint or non-obvious behavior. Preserve upstream license notices as legal text.

These instructions support authoring and review. They do not establish certification or replace the full standards.

References: [ISO 24495-1](https://www.iso.org/standard/78907.html), [ISO 24495-3](https://www.iso.org/standard/86938.html), and [ASD-STE100](https://www.asd-ste100.org/).
