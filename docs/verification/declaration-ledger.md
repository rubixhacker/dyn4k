The source revision is the fixed merge commit above; later ledger-only commits do not change its production source tree. `build_provenance.py` archives that exact Git revision, rebuilds it in isolation, and compares the complete JAR bytes. A free-form commit string or a baseline JAR copy cannot establish this provenance.

The validator compares the saved plain `javap -protected -s` inventory exactly. It reads a second, hash-checked `javap -protected -s -v` surface for member flags. The strict parser excludes compiler bridge methods; the ledger also records public and protected bridges from the verbose classfile inventory. The pinned inventory has 88 name-and-parameter groups with multiple returns: 64 pairs, 20 triples, and four groups of four. This adds 116 declarations to the earlier ledger. It records public, protected, bridge, and synthetic flags for each member. Its existing static method signatures omit redundant `final`; instance methods, types, and fields retain it.
