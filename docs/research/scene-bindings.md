## Dimensional settings and detector inventory

`scaleWorld` is intended for fresh, otherwise-default worlds and must be called once. It configures solver/detector units only; scene callers scale gravity, shapes, world positions, fixture speed thresholds and applied loads separately.

- Settings length fields multiplied by s: maximum translation, maximum rest linear speed, maximum warm-start distance, linear tolerance, maximum linear correction. Their squared caches are regenerated by setters. Time/angular settings, iteration counts, Baumgarte, booleans and CCD mode remain unchanged.
- Ordinary collision-item and swept-body CCD dynamic trees retain the default producer/filter classes and static expansion algorithm; expansion is `0.2*s`. Source: `AbstractCollisionWorld` and `AbstractPhysicsWorld` constructors.
- Each independently constructed GJK used by narrowphase, raycasting and conservative advancement has distance epsilon multiplied by s². Source `Gjk.distance`: the convergence expression is `(c.point.dot(d) - a.point.dot(d))`, where d is the closest-point vector, not normalized; this is squared length despite the setter's name. Raycast epsilon likewise compares `distanceSqrd` and scales by s².
- GJK detection epsilon is the pinned zero default and remains zero. Search-direction magnitudes are not uniformly normalized, so no nonzero substitute is introduced.
- Each GJK's EPA penetration solver has distance epsilon multiplied by s: support projection onto a normalized edge normal minus edge distance. Conservative advancement's own distance epsilon also scales by s. Iteration caps remain unchanged.
- ClippingManifoldSolver and LinkPostProcessor expose no configurable distance epsilon. Fixed `Epsilon.E`, fixed degeneracy/predicate thresholds and other internal constants remain unpatched. Consequently scaled-baseline similarity remains a diagnostic, never an assumed invariant.

CCD's first action records requested initial displacement, retained scaled maximum translation and whether that request exceeds the clamp. Capture must report actual solved-contact/TOI activation separately; NONE is a diagnostic and no-collision ALL runs are gaps, not successful CCD coverage. Stack rest activation and spring effective stiffness/energy likewise require examination of captured state; scene construction alone does not certify them.
