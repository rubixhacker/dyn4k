# Pilot before angular excitation

This 60-run pilot used the pinned dyn4j 6.0.0 binary, but the joint fixture did not apply a periodic angular impulse. The Angle modes could therefore remain inactive. The run is superseded and cannot qualify the final fixture. The raw CSV files, probe, analysis, and original evidence index are retained. Their index records the source hashes used at that time; those source versions are not the final harness.
