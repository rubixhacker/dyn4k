# dyn4k

An independently evolving Kotlin Multiplatform fork of dyn4j 6.0.0, planned around an idiomatic Kotlin API and a thin, fixed-version compatibility shim.

Status: The approved port is under implementation. The foundation provides
vectors, rotations, matrices, transforms, and the first public consumer tests.
Full engine coverage and target qualification remain open. Public repository:
[rubixhacker/dyn4k](https://github.com/rubixhacker/dyn4k).
