# dyn4k

An independently evolving Kotlin Multiplatform fork of dyn4j 6.0.0, planned around an idiomatic Kotlin API and a thin, fixed-version compatibility shim.

Status: implementation in progress. The complete port and its required runtime qualification are not yet finished. Public repository: [rubixhacker/dyn4k](https://github.com/rubixhacker/dyn4k).
